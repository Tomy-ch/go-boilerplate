# SQLC テンプレート

## 概要

SQLCを使用してデータベースクエリを生成するためのテンプレート

`.sqlc.template.yaml`を使用して、SQLCの生成場所などを設定します。

## engine

- **指定方法**: `engine` フィールドには、使用するデータベースエンジンを指定します。
- **例**: `postgresql` を指定することで、PostgreSQL用のクエリを生成します。

## database

- **uri**: データベース接続文字列を指定します。環境変数 `__DATABASE_URL__` を使用して動的に設定できます。
  - **例**: `postgres://user:password@localhost:5432/dbname`。
- **schema**: スキーマファイルのパスを指定します。スキーマが変更された場合に更新します。
  - **切り替えタイミング**: データベースが肥大化した場合、実行時間が長くなることがあります。その場合、スキーマを分割して管理することを検討することをおすすめします。

## gen/go

### package

- **指定方法**: 生成されるGoコードのパッケージ名を指定します。
- **例**: `gen` を指定すると、生成されたコードは `gen` パッケージに属します。

### out

- **指定方法**: 生成されたGoコードの出力先ディレクトリを指定します。
- **例**: `internal/infrastructure/rdb/sqlc/__TYPE__/__CATEGORY__/gen/` に生成されます。
  - `__TYPE__` や `__CATEGORY__` は、クエリの種類やカテゴリに応じて動的に置き換えられます。
