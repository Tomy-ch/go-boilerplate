# datetime

この層が外へ出す時刻のワイヤ表現を提供する。

## 役割

このパッケージは、ワイヤ上で瞬間をどう綴るかという唯一の規則を持つ — UTC、RFC 3339、ナノ秒精度。
ここへ集約することで、1 つの配送フレームに載る封筒とすべての event payload が同じ読み方になる。
builder ごとに決めさせない。

この規則があるのは、代替が安定しないからである。`time.Time` はロケーションを持ち、素の `Format` が
書き出すオフセットはデプロイ先の `TZ` の関数になる — 同じ瞬間が、ある環境では
`2026-09-01T10:00:00Z`、別の環境では `2026-09-01T19:00:00+09:00` と綴られる。公開された契約が
持ってよい性質ではない。`Z` しか受け付けない schema を書いた購読側は、API がどこで動くかによって
通ったり落ちたりする。

解決も解析もしない。時刻を読み戻すのは、その形式を所有する側の関心である — ページングカーソルが
自分のトークンを解析するのは、そのトークンが opaque で、発行したデプロイが自分で読み戻すからだ。

## 振る舞い

- どのロケーションでも → 同じ瞬間を UTC で綴る
- `time.Time` のゼロ値 → 同じ規則で綴る（`0001-01-01T00:00:00Z`）。値が無いことの判定は
  呼び出し側の責務であって、このパッケージのものではない

## 使い方

```go
payload := created{
    OrderedAt: datetime.FormatUTC(p.OrderedAt()),
}
```

`<集約>/event/` のパッケージが自分で時刻を整形した場合、`internal/architest` が落とす —
`internal/usecase/README.md` の `event/payload_parity.yaml` 節を参照。
