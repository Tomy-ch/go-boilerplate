# `testspan` パッケージ

概要: テスト実行時に Echo のリクエストコンテキストにテスト用のトレーススパンを埋め込み、テスト用スパンの終了処理を安全に行うためのユーティリティを提供します。主にテスト内でトレース情報を作成・検証したい場合に使用します。

## 役割

- テスト用のトレースコンテキスト（スパン）を Echo のリクエストに注入する。これにより、ハンドラ実行中にトレーシング情報を利用できるようにする。
- スパンの終了処理関数を返すことで、テスト側で defer により確実に終了処理（終了/フラッシュ等）を行えるようにする。

## 振る舞い（要点）

- テスト内で呼び出すと、リクエストのコンテキストをテスト用のトレースコンテキストに置き換え、終了用の関数を返します。
- グローバルトレーサが設定されている場合はそのスパン情報が有効になり、トレース ID / スパン ID を検証できます。
- グローバルトレーサが無い（デフォルト）場合でも安全に呼び出せる設計です（テスト実行を妨げません）。

## 使い方（振る舞いベース）

- Echo のテスト用コンテキストを用意し、テスト用スパン注入ユーティリティを呼び出します。返された終了関数はテストの最後に呼んでください（`defer` を推奨）。

- テスト内でトレース情報の存在を確認したい場合は、トレース取得ユーティリティでコンテキストからスパン情報を抜き出して検証します。

## テスト

- 単体テストでは、グローバルトレーサが設定されている場合のスパン有効化と、設定がない場合でも呼び出せることを検証しています。

## 必要度

### 本番運用での必須度

- 必須度: 不要
  - 理由: 本パッケージはテスト補助用であり、本番コードの実行には組み込まれません。

### 開発/テスト運用での必須度

- 必須度: 推奨
  - 理由: トレースを伴う統合テストや、ハンドラが期待通りにトレースを生成しているかを検証したい場合に有用です。

### 無効化した場合の影響

- 影響: テストでトレース情報の検証が行えなくなりますが、通常の機能テスト自体は継続可能です（ただしトレーシング関連のアサーションは行えません）。

## 注意点

- 返される終了関数は必ず呼び出してください（`defer` を推奨）。呼び出さないとテスト内で期待するスパンの終了処理が行われません。
- テスト側でグローバルトレーサを明示的にセットアップすることで、より厳密なトレース検証が可能です。
