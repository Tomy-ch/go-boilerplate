# `testinstance` パッケージ

概要: ハンドラ層のテストで使う「テスト用インスタンス」を生成するユーティリティ群です。Echo のインスタンスや gomock コントローラ、テスト用のロガー／トレーサなど、テストの初期化に共通で必要となるオブジェクトを簡潔に生成します。

## 役割

- テストで必要な共通リソース（Echo インスタンス、gomock コントローラ、テストロガー、テスト用トレーサファクトリ等）を生成する。
- 実装済みユースケースやハンドラのテストで使う、テスト用のコンテキスト・ロケーション・トレーサ等を用意する。

## 提供される振る舞い（要点）

- BindHandler をテストするための Echo インスタンスとモックコントローラ、テスト用トレーサ、テストロガーを返す。
- 実装済みユースケースのテストで使うためのベースコンテキスト、モックコントローラ、タイムゾーン（ロケーション）、レイヤ単位のテスト用トレーサを返す。

## 使用例（振る舞いベース）

- ハンドラ登録のテスト:
  - テスト内で Echo インスタンスとモックコントローラを生成し、`BindHandler` に渡してルート登録やルート検証を行う。

- ユースケース/エンドポイントの実装テスト:
  - テスト用のコンテキストとロケーション、トレーサを用いて、実装済みのユースケースやコントローラの振る舞いを検証する。

## テスト

- このディレクトリには単体テストが用意されており、生成されるインスタンスが nil でないことや、期待するロケーションが取得できることを検証しています。

## 必要度

### 本番運用での必須度

- 必須度: 不要
  - 理由: 本パッケージはテスト補助用であり、本番バイナリには組み込まれません。

### 開発/テスト運用での必須度

- 必須度: 必須（テストの実行性と品質確保のため推奨）
  - 理由: テストの初期化ロジックを共通化することで、テストコードの冗長性を減らし、モックやトレーサの準備を確実に行えます。

### 無効化した場合の影響

- 影響: 各テストで初期化コードを重複させる必要があり、モック設定やテスト用ロガー/トレーサの初期化漏れによるテスト不安定化を招く可能性があります。

## 注意点

- gomock のコントローラは各サブテスト内で生成し `defer Finish()` を使って片付けるパターンを推奨します（本ユーティリティはコントローラを生成しますが、`Finish()` の呼び出しはテスト側で行ってください）。
- テスト用トレーサやロガーはテストフレームワークに紐づくため、並列実行時は各サブテストで独立して生成することを推奨します。
