# `forcejson` パッケージ

概要: レスポンスの `Content-Type` が特定のブラックリスト（空もしくは `text/html` 系）に該当する場合、強制的に `application/json; charset=UTF-8` を設定する Echo ミドルウェアを提供します。

## 役割

`forcejson` は、API レスポンスが HTML 等の誤った Content-Type で返されることを防ぎ、クライアントが常に JSON として扱えるように Content-Type を補正します。主に JSON API を提供するサービスで、誤って HTML を返してしまう状況の緩和に利用します。

主要ファイル:

- `forcejson.go` : ミドルウェア実装（`Middleware()` を提供）。
- `forcejson_test.go` : 挙動を検証する単体テスト。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で任意（ケースにより推奨）

理由: 正しく実装されたハンドラであれば不要ですが、外部ライブラリや想定外のエラーで HTML が返る可能性がある場合、クライアント互換性の観点で有益です。サービス要件に応じて導入を検討してください。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨

理由: 開発時に誤って HTML が返る問題を早期に検出・緩和できるため、導入しておくとデバッグが楽になります。

### 無効化した場合の影響

ミドルウェアを適用しない場合、ハンドラから返された `Content-Type` がそのままクライアントに返却されます。誤って HTML を返した場合、クライアントが JSON として処理できずエラーになる可能性があります。

## 注意点

- 本ミドルウェアはヘッダの補正を行いますが、実際のレスポンスボディが HTML の場合は JSON として扱わせると問題が生じます。根本的にはハンドラ側で正しい Content-Type を設定することが重要です。
- `charset=UTF-8` を付加して返却します。必要に応じて実装を変更してください。
- テストは `forcejson_test.go` にあるため、CI での検証を推奨します。
