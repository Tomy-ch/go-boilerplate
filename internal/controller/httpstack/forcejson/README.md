# ForceJSON

概要: このディレクトリは、レスポンスのContent-Typeを強制的に`application/json`に設定するミドルウェアを提供します。

## 役割

- レスポンスのContent-Typeを統一し、クライアントが期待する形式でデータを受け取れるようにします。
- 特定のContent-Type (例: `text/html`) をJSON形式に変換することで、APIの一貫性を保ちます。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で推奨
  - 理由: 本番環境では、レスポンス形式の一貫性を保つことで、クライアント側の処理エラーを防ぐため推奨されます。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨
  - 理由: 開発やテスト環境でも、レスポンス形式の統一を確認するために推奨されます。

### 無効化した場合の影響

- レスポンスのContent-Typeが不一致となり、クライアント側でエラーが発生する可能性があります。
- APIの一貫性が損なわれ、デバッグやトラブルシューティングが困難になる可能性があります。

## 注意点

- このミドルウェアは、特定のContent-Type (例: `text/html`) をJSON形式に変換しますが、すべてのケースに対応しているわけではありません。
- 他のミドルウェアと組み合わせて使用する際、適切に動作することを確認してください。
- 必要に応じて、ブラックリストに登録するContent-Typeをカスタマイズしてください。
