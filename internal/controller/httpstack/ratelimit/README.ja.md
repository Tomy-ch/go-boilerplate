# ratelimit

[English](README.md) | 日本語

トークンバケットアルゴリズムによる IP ベースのレートリミットです。

## 公開 API

|関数 / 型|説明|
|---|---|
|`IPRateLimiter`|`AllowRequest(c) bool` と `Cleanup()` を持つインターフェース|
|`NewIPRateLimiter(ipLimitCfg)`|インメモリの IP 別レートリミッターを生成|
|`Middleware(rl, ipCfg)`|リミット超過時に 429 を返す Echo ミドルウェアを返す（ops エンドポイントはスキップ）|

## 制約: 水平スケーリングには適さない

この実装はレートリミットの状態を **インメモリ**（`sync.Mutex` + `map`）で保持します。各プロセスが独立したカウンタを持つため、マルチインスタンス構成では実効リミットが `設定値 × インスタンス数` になります。

水平スケーリングが必要な場合は、Redis（`INCR` + `EXPIRE`）や分散レートリミッターなどの共有ストアに置き換えてください。`IPRateLimiter` インターフェースにより、ミドルウェアやハンドラのコードを変更せず実装を差し替えられます。
