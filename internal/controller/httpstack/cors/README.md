# `cors` パッケージ

概要: CORS（Cross-Origin Resource Sharing）に関するミドルウェア設定を提供するパッケージです。アプリケーションのセキュリティ設定（`SecurityConfig`）に基づいて、許可するオリジンやメソッド、ヘッダを設定します。

## 役割

`cors` は Echo 用の CORS ミドルウェア設定を組み立て、アプリケーションで利用できる `echo.MiddlewareFunc` を返します。`Middleware(secCfg *config.SecurityConfig)` を使って、外部ドメインからのアクセス制御ポリシーを一元管理できます。

主要ファイル:

- `cors.go` : ミドルウェア生成の実装（`Middleware` と `buildCORSConfig`）。
- `cors_test.go` : 挙動を検証するテスト。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須

理由: 正しい CORS 設定はブラウザベースのクライアントからのアクセス制御に直接影響します。許可するオリジンを誤るとセキュリティリスクになるため、本番環境では明示的な設定が必須です。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨

理由: 開発時は緩めの設定（例: localhost を許可）で効率的に作業できますが、環境ごとに設定を切り替えられるように実装しておくと安全です。

### 無効化した場合の影響

このパッケージのミドルウェアを適用しない場合、ブラウザからのクロスオリジンリクエストが拒否されるか、予期せぬドメインからアクセスを受け入れてしまう可能性があります。API を公開するサービスでは必ず適切な CORS 設定を行ってください。

## 注意点

- `SecurityConfig.AllowedOrigins()` が正しく設定されていることを確認してください。
- `AllowCredentials` は現状 `false` に設定されています。必要に応じて実装を変更してください。
- テストは `cors_test.go` にあるため、CI での検証を推奨します。
