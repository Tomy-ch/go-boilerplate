# ErrorHandler

概要: このディレクトリは、HTTPエラーハンドリングのためのミドルウェアを提供します。エラーの正規化、レスポンス生成、ログ記録を行います。

## 役割

- HTTPエラーを正規化し、適切なレスポンスを生成します。
- エラーの詳細をログに記録し、デバッグやトラブルシューティングを支援します。
- リクエストIDをエラーレスポンスに付与します。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須
  - 理由: 本番環境でのエラーハンドリングは、アプリケーションの安定性とユーザー体験に直結するため必須です。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で必須
  - 理由: 開発中やテスト中にエラーの詳細を把握し、適切に処理するために必要です。

### 無効化した場合の影響

- エラーが適切に処理されず、ユーザーに不適切なレスポンスが返される可能性があります。
- エラーの詳細なログが記録されないため、デバッグやトラブルシューティングが困難になります。

## 注意点

- エラーハンドラーは、Echo フレームワークの `HTTPErrorHandler` をカスタマイズしています。
- エラーの正規化処理やログ記録の仕様を変更する場合は、`normalizeHTTPError` や `logHTTPError` 関数を適切に拡張してください。
- リクエストIDをレスポンスに含めることで、トラブルシューティングが容易になります。
