# `banner` パッケージ

概要: Echo サーバのバナー表示（起動時に表示される ASCII バナー）を制御する小さなユーティリティパッケージです。

## 役割

`banner` は、アプリケーション設定に基づいて Echo のバナー表示を有効/無効にします。`banner.New` を呼び出すと、`echo.Echo` の `HideBanner` をアプリ設定 (`ApplicationConfig`) の本番判定に合わせて設定します。

主要ファイル:

- `banner.go` : バナー表示制御の実装。
- `banner_test.go` : 挙動を確認する単体テスト。

## 必要度

### 本番運用での必須度

- 必須度: 本番環境で推奨

理由: バナー自体は必須ではありませんが、本番ログに不要な情報（バナー）を出力しないために、起動時に自動で非表示にすることは推奨されます。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨

理由: 開発中はバナーを表示してアプリの起動を視認しやすくすることが多いため、環境に応じて表示/非表示を切り替えられると便利です。

### 無効化した場合の影響

このパッケージをまったく使わない（呼び出さない）場合、Echo の既定のバナー表示設定がそのまま使われます。多くの場合は視覚的な違いのみで、機能的な影響はほとんどありません。ただし、本番環境でバナーを明示的に非表示にしたい要件がある場合は、`banner.New` を呼び出すことを忘れないでください。

## 注意点

- `ApplicationConfig` に `IsProductionMode()` メソッドが存在することを前提としています。
- バナー表示の制御は軽微な UI/ログの調整であり、セキュリティやビジネスロジックには影響しません。
- テストは `banner_test.go` にあるため、CI でテストが走る構成にしておくことを推奨します。
