# ops (運用系エンドポイント判定)

概要: `ops` パッケージは、運用系（ops）エンドポイントかどうかを判定するユーティリティを提供します。主に OpenAPI 検証やミドルウェアで検証対象から除外すべきパス（メトリクスやヘルスチェック等）を識別する目的で使用します。

## 役割

- `IsOpsPath(path string) bool` によって、与えられたパスが運用系エンドポイントかを判定します。末尾のスラッシュを正規化して判定します。
- 判定対象の既定パス: `/metrics`, `/health`, `/healthz`, `/ready`, `/version`。

## 必要度

### 本番運用での必須度

- 必須度: 推奨

理由: 運用・監視用のエンドポイントを検証や追加のミドルウェア処理から除外することで、低レイテンシな応答や不要なバリデーションエラーを避けられます。

### 開発/テスト運用での必須度

- 必須度: 推奨

理由: ローカルや CI においても同様に、ヘルスやメトリクスをシンプルに扱いたい場面が多いため、除外判定の仕組みがあると便利です。

### 無効化した場合の影響

- 無効化すると、これらのエンドポイントが通常のリクエスト処理と同じ検証やミドルウェア処理を受けるため、想定外のバリデーション失敗や遅延が発生する場合があります。

## 注意点

- 判定ロジックはパスの文字列比較に基づいています。要件に応じてパスを変更・追加してください。
- パス末尾の `/` を無視する正規化を行っていますが、パラメータを含むパス（例: `/health/:id`）には未対応です。必要な場合は実装を拡張してください。
