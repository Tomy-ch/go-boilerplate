# IPExtractor

概要: このディレクトリは、クライアントのIPアドレスを抽出するためのミドルウェアを提供します。環境に応じたIPアドレスの抽出方法を設定します。

## 役割

- クライアントのIPアドレスを抽出し、アプリケーションで利用可能にします。
- 本番環境では `X-Forwarded-For` ヘッダーからIPアドレスを抽出し、信頼できるIP範囲を設定します。
- 開発環境では直接IPアドレスを抽出します。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須
  - 理由: クライアントのIPアドレスを正確に取得することは、セキュリティやログ記録の観点で重要です。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨
  - 理由: 開発環境やテスト環境では、IPアドレスの抽出が必須ではない場合もありますが、動作確認のために推奨されます。

### 無効化した場合の影響

- クライアントのIPアドレスが正確に取得できなくなり、セキュリティ機能やログ記録に影響を与える可能性があります。

## 注意点

- 本番環境では、信頼できるIP範囲（CIDR）を正しく設定してください。
- 開発環境と本番環境で異なる抽出方法を使用するため、環境設定を適切に管理してください。
- デフォルトでは、本番環境に準じた抽出方法が使用されます。
