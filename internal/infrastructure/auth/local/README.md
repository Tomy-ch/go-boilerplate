# local (ローカル向け簡易認証)

概要: このディレクトリは、ローカル開発環境や CI / テスト環境で利用することを想定した、簡易的な `Authenticator` 実装を収めます。外部認証プロバイダや本番向けの認証基盤をエミュレートするための軽量な実装であり、本番運用での使用は想定していません。

## 役割

- 開発時やローカルでの手早い動作確認のために、アプリケーションが期待する認証情報 (`Authenticator` インターフェイス経由) を提供します。
- 本番で使われる本格的な認証サービスの代替として、簡易的に認証済みの主体（`Authn` 等）を返すことで、アプリケーションのフローや E2E の前段動作を検証できるようにします。

## 必要度

### 本番運用での必須度

- 必須度: 不要

理由: セキュリティ要件や運用要件を満たすための本格的な認証・認可基盤（外部プロバイダ、OIDC、JWT 検証など）に置き換える必要があります。本実装は検証・利便性を優先した簡易実装であり、本番利用には適していません。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨

理由: ローカルや CI 環境で外部認証を用意せずにアプリケーションの挙動を確認したいケースで有用です。テスト環境へ組み込むことで、テストのセットアップを簡素化できます。

### 無効化した場合の影響

- 開発環境やテストで本実装に依存している箇所がある場合、代替の `Authenticator` を DI で差し替えるか、認証機能をモック／スタブする必要があります。無効化したままにすると、認証が必要なエンドポイントやユースケースで認証エラーが発生します。

## 注意点

- 本実装は「利便性」を優先した簡易実装です。認証情報の検証（署名検証、トークン有効期限チェック、リプレイ防止など）を担保しない可能性があるため、本番運用では使用しないでください。
- 実際に本番用の `Authenticator` を組み込む場合は、`internal/di/module/auth.go` の `provideAuthenticator` 実装を差し替えてください。
- セキュリティに関わる設定や挙動（ヘッダーの取り扱い、テスト用の固定シークレットなど）がコード内に含まれている場合は、運用環境へ持ち込まないように注意してください。

## 実装に関するメモ

- ここで提供する実装は、外部サービスへの依存を取り除き、容易に認証されたコンテキストを作れることを目的としています。内部でどのように認証情報を構築するか（ヘッダー、環境変数、構成パラメータ等）は実装に依存します。
- 本実装をベースに、自動テスト用のフェイク認証や、開発者向けのログインショートカットを追加することができます。

## 置き換え方法

- 開発中やテスト実行時のみ本実装を使い、本番では本格的な `Authenticator` を使う運用が想定されます。`internal/di/module/auth.go` の `provideAuthenticator` 実装を編集して DI に差し替えてください。
