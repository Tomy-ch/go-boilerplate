# auth パッケージ

概要: このパッケージは、認証および認可に関連する機能を提供します。ユーザーの認証情報の抽出、認証の検証を行い、アプリケーションのセキュリティを確保します。

`Authenticator` を実装し、認証情報の抽出と検証を行います。

## 提供する主な機能

- `Authenticate` 関数: リクエストから認証情報を抽出し、検証します。

## 使い方

環境ごとやサービスごとに適切な `Authenticator` を実装し、アプリケーションの認証フローに組み込みます。

システムへの取り込みは、`internal/di/module/auth.go` の `provideAuthenticator` に実装を追加してください。
