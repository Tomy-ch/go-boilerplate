# `rdbtest` パッケージ

概要: テスト用の RDB 接続インスタンスやテスト向けトランザクション管理を提供するユーティリティ群です。リポジトリのユニット/統合テストで、実装済みインフラや New 関数の振る舞いを検証するときに使います。

## 役割

- テスト用の DB 接続インスタンス、ロギング付き DB プロバイダ、トレース用のダミーファクトリなどを生成する。
- 実装済みインフラのテスト時に利用できる、ロールバックを自動的に行うテスト用トランザクションマネージャーを提供する（テスト中の状態を DB に残さない用途）。

## 実装ファイルの概観

- テストインスタンス生成ロジック（設定読み込み → DB 接続 → ロガー/トレーサーのテストインスタンス生成）。
- テスト用トランザクション管理：与えた処理をトランザクション内で実行し、処理後に常にロールバックすることで副作用を残さない。

## 使い方（振る舞いベース）

- テスト実行時に、テスト用インスタンスを生成して返されるモック/プロバイダを各テストで使います（例: リポジトリの New() を呼ぶときの引数として渡す）。
- 実装済みインフラの検証では、トランザクションマネージャーを使ってトランザクション内で操作を行い、終了時にロールバックされることを利用してテストを独立させます。

## テスト

- 本ディレクトリには単体テストが含まれており、テストインスタンスの生成やトランザクションロールバックの挙動が検証されています。テストは `go test` で実行できます。

## 必要度

### 本番運用での必須度

- 必須度: 不要
  - 理由: 本パッケージは開発/テスト補助ツールであり、本番バイナリには組み込まれません。

### 開発/テスト運用での必須度

- 必須度: 必須（テスト品質維持のため推奨）
  - 理由: テスト中の DB 副作用を防ぎ、実装済みインフラの動作確認を容易にするため、テスト環境ではこれらのユーティリティを利用することを推奨します。

### 無効化した場合の影響

- 影響: テストの独立性が損なわれる可能性が高い（DB にテストデータが残る、テストの再現性が低下する等）。CI上でのテスト結果に信頼性の問題が出ることがあります。

## 注意点

- テスト用インスタンスは実際に DB コネクションを張るため、CI やローカルで動かす際にはテスト用の DB が利用可能であることを確認してください。
- テストではロールバックが行われるため、永続的な検証には別途専用のセットアップが必要です。
