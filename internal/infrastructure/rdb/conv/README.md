# conv

概要: `conv`ディレクトリは、`database/sql` のnullable型とポインタ型の相互変換を行うユーティリティを提供します。

## 役割

このディレクトリは、データベース操作で使用される `sql.NullString` や `sql.NullInt64` などのnullable型を、Goのポインタ型に変換する機能を提供します。

また、その逆変換もサポートしています。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須
  - 理由: データベースから取得したnullable型の値をアプリケーション内で扱いやすい形式に変換するために必要です。
  これにより、データの整合性と操作性が向上します。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で必須
  - 理由: 開発やテスト環境でも、データベース操作の検証やデータ変換ロジックのテストに必要です。

### 無効化した場合の影響

このディレクトリの機能が無効化されると、データベースから取得したnullable型の値を手動で変換する必要が生じ、実装やテストの複雑さが増します。

## 注意点

- 各関数は、nullable型とポインタ型の変換を双方向でサポートしています。
- テストコードでは、正常系と異常系の両方を十分に検証しています。
- データベース操作における型の整合性を保つために、このユーティリティを適切に利用してください。
