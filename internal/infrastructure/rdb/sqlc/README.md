## sqlc Package

English | [日本語](README.ja.md)

This directory provides the result of generating Go code from SQL using [sqlc](https://docs.sqlc.dev/), and  
**SQL execution-related utilities** that support them.

The responsibilities of this package are as follows:

1. **Placement of code generated by sqlc**
2. **Provision of helper functions to handle generated code in a practical way**

## About Generated Code

- The `gen/` directory contains Go code generated by sqlc.
- These code files **must not be edited manually.**
- When SQL queries or schemas are changed, run `sqlc generate` to regenerate the code.

The generated code provides the following features:

- Type-safe execution of SQL queries
- Parameter binding
- Mapping of DB records to Go types

## Helper Utilities

This directory contains **SQL execution helper functions** to complement sqlc-generated code.

The main purposes are as follows:

- Pattern generation for LIKE / ILIKE searches
- PostgreSQL LIKE escaping

These are used as **Infrastructure-layer utilities**.

## Directory Structure

```text
internal/infrastructure/rdb/sqlc/
├── like.go         # LIKE search helpers
└── gen/            # sqlc auto-generated code (do not edit)
    ├── desc.go     # Package description
    ├── *.sql.go    # Query execution code (auto-generated)
    └── *.gen.go    # Type definitions (auto-generated)
```

## Public API

|Function / Constant|File|Description|
|---|---|---|
|`DefaultLikeEscapeChar`|`like.go`|Default escape character (`\\`)|
|`EscapeForLike(s, esc)`|`like.go`|Escape LIKE special characters (`%`, `_`, escape char)|
|`WrapPrefixLikePattern(token)`|`like.go`|Generate prefix match pattern (`token%`)|
|`WrapSuffixLikePattern(token)`|`like.go`|Generate suffix match pattern (`%token`)|
|`WrapContainsLikePattern(escaped)`|`like.go`|Generate partial match pattern (`%escaped%`)|

## LIKE Search Helpers

Provides functions to assist in generating patterns used in PostgreSQL `LIKE` / `ILIKE` searches.

### EscapeForLike

Escapes the following characters that have special meaning in `LIKE` searches:

- `%`
- `_`
- the escape character itself

```go
escaped := EscapeForLike(keyword, DefaultLikeEscapeChar)
```

`DefaultLikeEscapeChar` has the following value:

```go
const DefaultLikeEscapeChar = "\\"
```

On the SQL side, it is used as follows:

```sql
WHERE name ILIKE $1 ESCAPE '\\'
```

### LIKE Pattern Generation

Helpers for generating patterns for LIKE searches.

#### Prefix match

```go
pattern := WrapPrefixLikePattern(token)
```

Result: `token%`

#### Suffix match

```go
pattern := WrapSuffixLikePattern(token)
```

Result: `%token`

#### Partial match

```go
escaped := EscapeForLike(keyword, DefaultLikeEscapeChar)
pattern := WrapContainsLikePattern(escaped)
```

Result: `%escaped%`

##### **Important**

For `LIKE` searches, always execute `EscapeForLike` before generating the pattern.

## Design Policy

This package is an **Infrastructure-layer dedicated helper library**.

It has the following responsibilities:

- Utilities related to SQL execution
- Supporting processing for sqlc-generated code
- Absorbing DB-specific behavior

On the other hand, it does not have the following responsibilities:

- Domain logic
- Usecase logic
- HTTP / Controller processing

These belong to:

- Domain layer
- Usecase layer
- Controller layer
