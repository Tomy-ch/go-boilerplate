## sqlc Package

English | [日本語](README.ja.md)

This directory provides the code generated from SQL using [sqlc](https://docs.sqlc.dev/) and  
**SQL execution utilities** that assist in working with the generated code.

The responsibilities of this package are:

1. **Hosting code generated by sqlc**
2. **Providing helper functions to make the generated code practical to use**

## Generated Code

- The `gen/` directory contains Go code generated by sqlc.
- These files **must not be edited manually.**
- When SQL queries or schemas change, regenerate the code by running `sqlc generate`.

The generated code provides:

- Type-safe execution of SQL queries
- Parameter binding
- Mapping database records to Go types

## Helper Utilities

This directory also contains **SQL execution helper utilities** that complement the sqlc-generated code.

Typical purposes include:

- Generating patterns for `LIKE` / `ILIKE` searches
- Escaping PostgreSQL `LIKE` patterns
- Converting values to sqlc-generated Enum types

These utilities are intended to be used as **Infrastructure-layer helpers**.

## LIKE Search Helpers

Functions are provided to help generate patterns used in PostgreSQL `LIKE` / `ILIKE` searches.

### EscapeForLike

Escapes characters that have special meaning in `LIKE` queries:

- `%`
- `_`
- the escape character itself

+++go
escaped := EscapeForLike(keyword, DefaultLikeEscapeChar)
+++

`DefaultLikeEscapeChar` is defined as:

+++go
const DefaultLikeEscapeChar = "\\"
+++

In SQL, it is typically used like this:

+++sql
WHERE name ILIKE $1 ESCAPE '\\'
+++

### LIKE Pattern Generation

Helpers for generating search patterns.

#### Prefix match

+++go
pattern := WrapPrefixLikePattern(token)
+++

Result: `token%`

#### Suffix match

+++go
pattern := WrapSuffixLikePattern(token)
+++

Result: `%token`

#### Contains match

+++go
escaped := EscapeForLike(keyword, DefaultLikeEscapeChar)
pattern := WrapContainsLikePattern(escaped)
+++

Result: `%escaped%`

#### **Important**

For `LIKE` searches, always run `EscapeForLike` before generating the pattern.

## Enum Conversion Helpers

Helper functions are provided to convert values into sqlc-generated Enum types.

Currently, conversion for `DeletedState` is supported.

### BoolPtrToDeletedState

Converts `*bool` to `gen.DeletedState`.

|Input|Result|
|---|---|
|nil|DeletedStateAll|
|true|DeletedStateDeleted|
|false|DeletedStateActive|

Example:

+++go
state := BoolPtrToDeletedState(filter.Deleted)
+++

### BoolToDeletedState

Converts `bool` to `gen.DeletedState`.

|Input|Result|
|---|---|
|true|DeletedStateDeleted|
|false|DeletedStateActive|

Example:

+++go
state := BoolToDeletedState(isDeleted)
+++

## Design Policy

This package is an **Infrastructure-layer helper library**.

It has the following responsibilities:

- Utilities related to SQL execution
- Supporting logic for sqlc-generated code
- Absorbing database-specific behavior

On the other hand, it **must not contain**:

- Domain logic
- Usecase logic
- HTTP / Controller logic

These responsibilities belong to:

- Domain layer
- Usecase layer
- Controller layer
