# sqlc パッケージ

このディレクトリは、[sqlc](https://docs.sqlc.dev/) を使用して SQL から Go コードを生成した結果と、実行するための汎用関数群を含みます。

## 生成コードについて

- `gen/` ディレクトリ以下には、sqlc によって生成された Go コードが含まれます。これらのコードは手動で編集しないでください。SQL クエリやスキーマを変更した場合は、sqlc コマンドを再実行してコードを再生成してください。
- 生成コードは、SQL クエリの実行、パラメータのバインディング、結果のスキャンなどを行うための型安全な関数を提供します。

## 汎用関数について

- このディレクトリには、sqlc で生成されたコードを補完するための汎用関数やヘルパー関数が含まれています。これらの関数は、曖昧検索のためのワイルドカード付与や、Enum 型の変換など、アプリケーション固有のロジックを実装するために使用されます。
