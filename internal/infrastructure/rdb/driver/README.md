# RDB Infrastructure

概要: このディレクトリは、RDB (Relational Database) との接続やトランザクション管理、それらのロギング機能を提供します。

## 役割

- RDBとの接続を管理し、アプリケーションからのデータベース操作をサポートします。
- トランザクション管理を提供し、データの整合性を確保します。
- ロギング機能を提供し、データベース操作の監査やトラブルシューティングを容易にします。

## sql.DBのバージョンアップ方法

- 生成側の `DBTX` インターフェイスに新しいメソッドが追加された場合、このインターフェイスを更新する必要があります。
  - このインターフェイスは、RDBMSが期待する最小限のインターフェイスであり、sql.TXとsql.DBを出し分けるために使用されます。
- 必要に応じて、`ResolveDriverWithLog` 関数やリポジトリの実装を修正してください。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須
  - 理由: 本番環境では、データベース接続やトランザクション管理が適切に行われないと、データの整合性が損なわれる可能性があるため必須です。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で必須
  - 理由: 開発/テスト環境では、データベース接続やトランザクション管理が適切に行われないと、データの整合性が損なわれる可能性があるため必須です。

### 無効化した場合の影響

- データベース接続が確立されず、アプリケーションが正常に動作しなくなります。
- トランザクション管理が行われないため、データの整合性が損なわれる可能性があります。
- ロギング機能が無効化されるため、データベース操作の監査やトラブルシューティングが困難になります。

## 注意点

- データベース接続の設定 (例: 最大接続数、接続の有効期限) を適切に管理してください。
- トランザクション内でのエラー処理を適切に実装し、データの整合性を確保してください。
- リポジトリの実装は、ビジネスロジックとデータベース操作を分離するように設計してください。
