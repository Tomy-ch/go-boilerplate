# logging

概要: `logging` ディレクトリは、アプリケーションのロギング機能を提供します。

環境に応じたログ設定を行い、開発・本番運用の両方で利用可能なロガーを生成します。

## 役割

このディレクトリは、`zap` ライブラリを使用して、開発環境および本番環境に適したロガーを提供します。

ログのフォーマットや出力先を環境に応じて設定し、アプリケーション全体で一貫したロギングを実現します。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須
  - 理由: ログはアプリケーションの動作状況を監視し、問題のトラブルシューティングを行うために不可欠です。
    本番環境では、JSON フォーマットの構造化ログを出力します。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で必須
  - 理由: 開発環境では、デバッグ情報を含む詳細なログを出力し、問題の特定や修正を容易にします。
    テスト環境でも、ログを通じて動作確認が可能です。

### 無効化した場合の影響

ロギング機能が無効化されると、アプリケーションの動作状況を把握する手段が失われ、問題の特定や解決が困難になります。

また、運用中の障害対応が遅れる可能性があります。

## 注意点

- 本番環境では JSON フォーマット、開発環境ではコンソールフォーマットのログを出力します。
- ログレベルや出力先は、`zap.Config` を通じて柔軟に設定可能です。
- テストコードでは、各ロガーの生成と動作を検証しています。
