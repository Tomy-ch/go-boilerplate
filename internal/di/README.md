# di

概要: `di`ディレクトリは、アプリケーションの依存関係を管理し、モジュール化された構成を提供します。

## 役割

このディレクトリは、`go.uber.org/fx`を使用して、アプリケーションの各種モジュール (例: Config, Database, Logging, HTTPStack, Server)をDI(Dependency Injection)の形で提供します。

## 必要度

### 本番運用での必須度

- 必須度: 本番運用で必須
  - 理由: アプリケーションの主要な依存関係 (例: データベース接続、ログ設定、HTTP サーバー) を管理し、正しく初期化するために必要です。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で必須
  - 理由: 開発環境やテスト環境でも、依存関係の管理とモジュールの初期化が必要です。

### 無効化した場合の影響

このディレクトリを無効化すると、アプリケーションの主要な依存関係が初期化されず、アプリケーションが正常に動作しなくなります。

## 注意点

- 各モジュールは `fx.Module` を使用して定義されており、必要に応じて追加や変更が可能です。
- 追加方法は、[internal/di/implementation.md](./implementation.md) を参照してください。
