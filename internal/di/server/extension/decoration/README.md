# decoration

概要:
`decoration` は **サーバー起動時の視覚的・初期表示に関する機能（バナー表示 / デフォルトポート設定）を DI 経由で提供するレイヤー** です。
アプリケーションが起動した際に、開発者が即座に状況を把握できるようにする「起動時の装飾」機能をまとめています。

## 役割

- **バナー表示（Banner）**
  - サーバー起動時にアプリケーション名・環境・バージョンなどを表示
  - 開発者が起動状況を視覚的に確認できる

- **デフォルトポート設定（DefaultPort）**
  - Echo サーバーのポート番号を `ApplicationConfig` に基づいて設定
  - ローカル・本番環境で一貫した動作を保証

## 必要度

### 本番運用での必須度

- 必須度: **本番運用で推奨**

理由:

- バナー表示は必須ではないが、ログとして起動情報を明確に出すことができる
- デフォルトポート設定は本番環境の整合性を保つために有用
- 起動時の情報を記録することで運用ログが改善される

### 開発/テスト運用での必須度

- 必須度: **開発/テスト運用で必須**

理由:

- ローカル開発では、サーバーが正しく起動したかどうかを即時確認するため必要
- バナー表示によって環境情報を視覚的に把握しやすく、ミスを減らせる
- 開発中のサーバー設定（ポート・環境）の確認が容易になる

## 無効化した場合の影響

- サーバー起動時の情報が視覚的に得られず、起動状態の把握が難しくなる
- ローカル環境でポート設定が明示されず、起動ミスを検知しにくい
- 本番環境の起動ログが不足し、トラブル時の調査が難しくなる可能性がある

**→ クリティカルではないが、開発効率と運用性が低下する。**

## 注意点

- バナー表示は UI 的な装飾のため、**ビジネスロジック（domain/usecase）に依存させないこと**
- DefaultPort は `ApplicationConfig` に依存するため、環境差異に注意
- 本番環境ではバナー表示が不要な場合、アプリ設定で無効化することも可能
- decoration はあくまで「サーバー起動時の補助」であり、本質的なミドルウェアと混在させないこと
