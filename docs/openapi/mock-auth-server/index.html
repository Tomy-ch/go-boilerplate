Mock Auth Server (OIDC Provider) (1.0.0)

Download OpenAPI specification:

License: MIT License

ローカル開発用の疑似 OIDC Provider。Authorization Code Flow + PKCE(S256) を最小構成で提供する。

本サービスは go-boilerplate 本体とは別サービスであり、OpenAPI をこのディレクトリ配下にローカルで持つ （主 API 契約 openapi/ は汚さない）。エンドポイントは 3 系統に分かれる:

  • /oidc/* — OAuth2 / OIDC 標準エンドポイント（authorize / token / userinfo / logout）。
  • /bypass/* — テスト用ショートカット（固定 Profile での token / session 発行）。dev-gate 限定。
  • /admin/* — 運用補助（fixture reset / users 一覧 / key rotate スタブ）。dev-gate 限定。

パラメータ・フィールドは OAuth2(RFC 6749) / PKCE(RFC 7636) / RFC 9068 / OIDC Core に従い snake_case。

oidc

署名鍵ローテーション

宣言的操作（add-key / promote / retire）で provider の署名鍵状態を遷移する。 JWKS の公開集合と現署名鍵を分離管理し、新旧 Token の並行検証・旧鍵退役を再現する。 Phase1 への復帰は POST /admin/reset。dev-gate 限定。

Request Body schema: application/json
required
action
required
string
Enum: "add-key" "promote" "retire"

鍵ライフサイクル操作。add-key=公開集合へ追加（署名鍵は不変）/ promote=署名鍵へ昇格（公開済みが前提）/ retire=公開集合から退役（現署名鍵は退役不可）。
