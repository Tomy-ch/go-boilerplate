type Migrator ¶

Migrator は、golang-migrate の操作を抽象化し、テストでモック差し替え可能にします。 

type Migrator interface {
    Up() error
    Down() error
    Steps(n int) error
    Version() (version uint, dirty bool, err error)
    Force(version int) error
}
