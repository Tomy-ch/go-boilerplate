Package withdrawalarchive は、退会イベントを消費して退会証跡を保存する worker を提供します。 outbox が publish した user.withdrawn.v1 を broker 経由で受け取る、consuming 端の実装例です。

New は、退会証跡 worker を初期化します。 broker adapter（Consumer / FailureHandler）は呼び出し側が組み立てて渡すため、この worker は どの broker から読んでいるかを知りません。 failure に nil を渡した場合、Permanent メッセージの退避は engine 既定の扱いになります。
