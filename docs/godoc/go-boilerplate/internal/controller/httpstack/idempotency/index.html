func Middleware ¶ 

func Middleware() func(next NextFunc, operationID string) NextFunc

Middleware は、冪等性入り口を StrictMiddleware の構造的シグネチャで返します。 採用する handler パッケージが自身の gen.StrictMiddlewareFunc へ変換して差します。

func StrictMiddleware ¶ 

func StrictMiddleware[H ~func(ec echo.Context, request any) (any, error)]() func(f H, operationID string) H

StrictMiddleware は、Middleware() を oapi-codegen のパッケージ固有 StrictMiddlewareFunc 形へ 適合させたアダプタを返します。型引数に各 gen パッケージの StrictHandlerFunc を渡して差します。
