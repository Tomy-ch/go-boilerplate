func NewHTTPErrorFromAppError ¶ 

func NewHTTPErrorFromAppError(err error, details ...string) *HTTPErrorResponse

NewHTTPErrorFromAppError は、err をアプリケーションエラーとして解釈し、対応する HTTP エラーレスポンスを返します。 既知のエラー型に一致しない場合は 500 Internal Server Error として扱います。 err に apperror.Meta が付与されている場合、非空の Code / Message は既定値を上書きし、 Details は明示引数 details が無い場合にのみ採用されます。HTTP ステータスはセンチネル分類のまま変わりません。

func NewHTTPErrorFromStatus ¶ 

func NewHTTPErrorFromStatus(httpStatus int, err error, details ...string) *HTTPErrorResponse

NewHTTPErrorFromStatus は、指定されたHTTPステータスコードに対応するHTTPエラーレスポンスを生成します。 err はログ出力用の元エラーとして Internal に格納されます。

func (*HTTPErrorResponse) Error ¶ 

func (e *HTTPErrorResponse) Error() string

Error メソッドは、HTTPエラーレスポンスの文字列表現を返します。
