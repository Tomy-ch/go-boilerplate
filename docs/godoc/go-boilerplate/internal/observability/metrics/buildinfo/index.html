Overview ▾

Package buildinfo は、アプリケーションのビルド・バージョン・ランタイム情報を Prometheus の info gauge (app_build_info) として公開する機能を提供します。

値は常に 1 であり、意味はラベル (service / environment / version / revision / build_date / go_version) に持たせます。これらの値はプロセス起動後に変化しない ため、ラベル値は DI 結線時に一度だけ解決・正規化して保持し、スクレイプごとの 計算は行いません。
