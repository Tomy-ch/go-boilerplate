func EnsureRepoRootAndEnv ¶ 

func EnsureRepoRootAndEnv(t *testing.T, env string)

EnsureRepoRootAndEnv は、go.mod のあるリポジトリルートへ作業ディレクトリを移動し、 env/.env.<env> の各値を t.Setenv で設定します。埋め込み（local）より対象環境の値が優先されます。 作業ディレクトリと環境変数の復元は t.Chdir / t.Setenv が自動で行います。
