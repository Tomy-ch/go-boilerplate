func NewDownstreamProfile ¶ 

func NewDownstreamProfile() httpclient.DownstreamProfile

NewDownstreamProfile は、外部郵便番号 lookup サービス向けの resilient プロファイルを返します。 外部サービスのため trace を伝搬せず、private/loopback 宛て接続を拒否します。

func RequiredDownstream ¶ 

func RequiredDownstream() httpclient.Downstream

RequiredDownstream は、本 gateway が使用する Downstream を返します。 required_downstreams へ供給することで、対応 profile が未登録のまま起動した場合に silent な DefaultProfile fallback ではなく loud な起動失敗になることを保証します。
