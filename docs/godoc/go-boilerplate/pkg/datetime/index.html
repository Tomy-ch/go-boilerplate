func ParseRFC3339UTC ¶ 

func ParseRFC3339UTC(s string) (time.Time, error)

ParseRFC3339UTC は、末尾が Z（UTC 表記）の RFC3339 文字列のみを解析します。 レイアウト末尾はリテラル Z 固定のため、オフセット付き入力（例 +09:00）は受理しません。
