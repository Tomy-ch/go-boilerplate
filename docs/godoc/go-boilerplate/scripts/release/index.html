Command release

Package main は、リリースタグとリリースブランチを作成するツール。 

tag    -bump <patch|minor|major>                     production HEAD にタグを打ち、GitHub Release を作る
branch -bump <patch|minor|major> -prefix <接頭辞>     次バージョンのブランチを切り、デフォルトブランチに設定する

どちらも `git tag` の最新セマンティックバージョンを起点に次バージョンを決める。

実体が make のレシピではなくここに在るのは、いずれも取り消しの効かない操作 （タグの push / GitHub Release の作成 / デフォルトブランチの切り替え）を含み、 分岐を実地で確かめようとすると本当にリリースするしかないため。手順の組み立てと 中止条件を純粋関数へ寄せて、テストで固定する。

git / gh はホストの認証情報を使うため、ツールランナーではなくホストで実行する （cmd/db-slot と同じ扱い）。
