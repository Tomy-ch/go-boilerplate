Package yamlblock は YAML のブロックスカラー（`key: |` / `key: >-`）の中身の判定を 1 箇所へ集める。

呼び出し側は 2 つある。`uses: owner/repo@<sha>` の取りこぼしを検出する pin-actions と、 `uses: docker://<image>:<tag>` の取りこぼしを検出する pin-images である。どちらも 「厳格なパターンで潰した残り」を行単位で走査するため、ブロックスカラーの中身を外さなければ `run:` スクリプトが `uses:` を含む文字列を出力するだけで検出が誤爆する。

片方だけが除外すると、同じ workflow が経路によって違う判定を受ける。

func ContentLines(data string) map[int]bool

ContentLines は data のうちブロックスカラーの中身に当たる行番号（1 始まり）を返す。

中身の範囲は字下げで決まる。ヘッダ行より深い字下げの行と、その途中の空行が中身で、 字下げがヘッダ以下へ戻った行で終わる。ヘッダ行そのものは中身に含めない。
