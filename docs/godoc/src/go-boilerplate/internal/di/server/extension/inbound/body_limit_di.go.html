    11  // bodyLimitPrePriority は、body limit ミドルウェアの Pre 適用順序です。
    12  // OpenAPI validator（Use=6）が requestBody を読む前に確実に上限を適用するため Pre に置きます。
    13  // uri=1・deadline budget の timeout=2 の後（Pre=3）に置く。timeout が設定した budget の内側に入るため、
    14  // body 読み取りも budget 内に収まります。
    15  const bodyLimitPrePriority = 3
