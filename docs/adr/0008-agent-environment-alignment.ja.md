# ADR-0008: 宣言可能かつ検証可能な性質を中心にエージェント環境を整合させる

English canonical: [0008-agent-environment-alignment.md](0008-agent-environment-alignment.md)

## ステータス

accepted

## コンテキスト

本リポジトリには、正本ドキュメント、保護パス、レイヤ規則、生成物ゲート、skill、review、runtime
確認によるエージェント作業の制約が既にある。しかし個別に採られた機構を束ね、後から加える制御を
どう判断するかを示す決定はない。

外部では類似の実践を "harness engineering" と呼ぶが、用語と定義は未確立である。長命な
テンプレートをその語彙へ結びつけても、検証性は高まらない。

## 決定

外部ラベルへの準拠ではなく、リポジトリ自身の検証可能な性質に整合することを宣言する。制御は、
明確な指示、決定可能な性質への機械的強制、または決定不能な性質への独立に検討可能な signal を
提供しなければならない。

個別規則の正本は既存機構に残す。決定可能な性質は tooling で gate し、読解を要する判断は
ADR-0090 の finder-to-verifier review で扱う。`ci-first` は、飽和した host の失敗を信頼できる
signal と誤認しないため、重い local gate を CI へ委譲する。既存機構が確実に再浮上させる signal
は、永続的な人間作業として escalation しなくてよい。

## 帰結

### ポジティブな帰結

- 揺動する外部用語に依存せず、明示した性質で新しい制御を判断できる。
- ドキュメント、skill、hook、CI は競合する方針保管庫ではなく補完関係に保たれる。
- 機械的 gate と人間判断の境界が明示される。

### ネガティブな帰結

- 外部チェックリストへの準拠は主張しない。
- 後続作業はこの決定と解釈・維持 artifact の同期を保つ必要がある。

## 検討した代替案

### "harness engineering" への準拠を宣言する

外部用語が未確立であり、宣言が現在の意味を超えて残るため不採用。

### 傘となる宣言を置かない

既存機構を一つの体系として評価しにくいまま残るため不採用。
