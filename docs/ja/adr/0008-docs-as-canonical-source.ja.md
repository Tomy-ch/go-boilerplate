# ADR-0008: ドキュメントを正典ソースとする戦略（英語正典 + ja ミラー + ポータル）

English canonical: [0008-docs-as-canonical-source.md](../../adr/0008-docs-as-canonical-source.md)

## ステータス

accepted

## 背景

このプロジェクトのドキュメントは、異なるニーズを持つ 2 つの読者層にサービスを提供している。

- **AI エージェント** — 正確で曖昧さのない英語の技術文章が必要で、それによって正しいコードを生成し、正しいワークフローに従う。単一の権威あるソースを読む必要があり、翻訳を読むと翻訳ラグのリスクが生じる。
- **人間の開発者** — 日本語を好む場合がある。生の Markdown ファイルよりもナビゲート可能なポータルから恩恵を受ける。

3 つの構造的な懸念が生じる：

1. 英語と日本語のドキュメントが明確な優先順位規則なしに並行して保守されると、乖離する。乖離した翻訳はそれを読んだ読者を誤解させる。
2. ポータルがソースファイルではなく主要なドキュメントサーフェスである場合、ポータル生成の失敗がドキュメントへのアクセスをブロックし、ポータル形式がコンテンツの制約になる。
3. 安定したディレクトリ規約なしにドキュメントが散在すると、ジェネレーター（`scripts/gen-docs-json.mjs`）やエージェントハーネス（`AGENTS.md`）が正典コンテンツを確実に特定できない。

## 決定

3 層のドキュメント戦略を採用する：

1. **英語正典** — `docs/**/*.md`（`docs/ja/**` と `docs/portal/**` を除く）が権威あるソースである。エージェントが読むもの、ルールが参照するもの、ポータルがレンダリングするものである。
2. **日本語ミラー** — `docs/ja/**/*.ja.md` ファイルは英語正典ドキュメントの人間が保守する翻訳である。エージェントはこれを読まない（`AGENTS.md` に従い、エージェントは `*.ja.md` ファイルを読んではならない）。命名規約: `docs/ja/` 配下の並列ディレクトリ構造に `<name>.ja.md` 形式で配置する。
3. **生成ポータル** — `docs/portal/docs.json` と `docs/portal/guides/**` は、`docs/portal/manifest.yaml` に駆動されて `scripts/gen-docs-json.mjs` が正典ソースから生成する。ポータルコンテンツは手動で編集してはならない。

`docs/portal/manifest.yaml` はポータルの構造制御ファイルである。ソースファイルをポータルの宛先にマッピングし、ナビゲーション階層（グループ、セクション、サブグループ）を定義し、セクションの表示タイトルを制御する。人間が保守する。

以下のディレクトリはジェネレーターによって予約されており、通常のドキュメントセクションとして使用できない: `docs/portal`、`docs/openapi`、`docs/coverage`、`docs/er-diagram`、`docs/ja`。

## 影響

### ポジティブな影響

- AI エージェントは単一の明確な読取対象（英語正典）を持つ。規則はエージェントハーネスで強制できる。
- 翻訳ラグが制限される。日本語ミラーは英語の更新より遅れる場合があるが、英語正典は常に権威ある状態を保つ。
- ポータルコンテンツはソースから常に再生成可能である。`docs/portal/docs.json` は生成成果物であり、どのマシンや CI ランナーでも再生成できる。
- 新しいドキュメントセクションの追加は明確な規約に従う: 英語 `docs/<section>/` ディレクトリ、並列 `docs/ja/<section>/` ディレクトリ、および `docs/portal/manifest.yaml` へのエントリ。

### ネガティブな影響

- すべてのドキュメントを 2 言語で維持するのは労力を要する。日本語ミラーは英語正典の更新に遅れる場合がある。
- 新しいセクションが追加・名称変更された場合に `docs/portal/manifest.yaml` を更新しなければならない。古いマニフェストは新しいドキュメントがポータルに表示されない原因になる。
- 予約ディレクトリリストは新しいドキュメントセクションの命名の選択肢を制限する。

## 検討した代替案

### 単一言語（英語のみ）

日本語翻訳を完全に廃止する。メンテナンスはシンプルになるが、このテンプレートの主要な採用者である日本語を話す開発チームのアクセシビリティが低下する。

### 自動翻訳

英語から日本語翻訳を自動生成する。却下：機械翻訳の品質は正確な技術コンテンツには不十分であり、誤訳されたアーキテクチャルールは開発者を誤解させる可能性がある。

### ポータルをプライマリソースとする

ポータルのネイティブ形式でドキュメントを保守し、そこから Markdown を導出する。却下：ポータルはレンダリングの関心事であり、正典ソースとすることでコンテンツが特定のレンダリングパイプラインに縛られ、エージェントによる直接消費が複雑になる。
