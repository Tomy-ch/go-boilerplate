# Documentation Structure Rules

This repository uses an **automatically generated documentation portal**.

The portal (`docs/portal`) reads `docs.json`, which is generated by:

```txt
scripts/generate-docs-json.js
```

To ensure the generator works correctly, the following rules must be respected.

## 1. Root Documents

English documentation must be placed directly under:

```txt
docs/
```

Example:

```txt
docs/
├ architecture.md
├ development-flow.md
├ decisions.md
└ rules.md
```

These files will appear in the **Architecture (English)** section.

## 2. Japanese Documents

Japanese documents must be placed under:

```txt
docs/ja
```

File naming convention:

```txt
<name>.ja.md
```

Example:

```txt
docs/ja
├ architecture.ja.md
├ development-flow.ja.md
├ decisions.ja.md
└ rules.ja.md
```

These files will appear in the **Architecture (Japanese)** section.

## 3. Section Documents

Subdirectories create documentation sections automatically.

Example:

```txt
docs/project
docs/maintenance
```

Each markdown file inside becomes a page.

Example:

```txt
docs/project
├ policy.md
├ scope.md
└ versioning.md
```

Generated section:

```txt
Project (English)
```

## 4. Japanese Section Documents

Japanese versions must mirror the same structure inside:

```txt
docs/ja/<section>
```

Example:

```txt
docs/ja/project
├ policy.ja.md
├ scope.ja.md
└ versioning.ja.md
```

Generated section:

```txt
Project (Japanese)
```

## 5. Reserved Directories

The following directories are **reserved and ignored by the generator**.

```txt
docs/portal
docs/openapi
docs/coverage
docs/er-diagram
docs/ja
```

## 6. Portal Files

The following files are generated automatically and should not be edited manually:

```txt
docs/portal/docs.json
```

To regenerate:

```txt
node scripts/generate-docs-json.js
```

## 7. Adding a New Documentation Section

To add a new section:

```txt
docs/security
docs/ja/security
```

Example:

```txt
docs/security/auth.md
docs/ja/security/auth.ja.md
```

The portal will automatically generate:

```txt
Security (English)
Security (Japanese)
```

## 8. CI Integration

The documentation portal is updated automatically in CI:

```sh
node scripts/generate-docs-json.js
```

## Summary

|Location|Language|
|--------|--------|
|docs/*.md|English|
|docs/ja/*.ja.md|Japanese|
|docs/<section>|English section|
|docs/ja/<section>|Japanese section|

Following these rules ensures the documentation portal stays consistent.
