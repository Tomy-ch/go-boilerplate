# Documentation Structure Rules

This project uses an **automatically generated documentation portal**.

The portal (`docs/portal`) reads `docs.json`.  
This file is generated by the following script.

```txt
scripts/gen-docs-json.mjs
```

To ensure this generation process works correctly, the following rules must be followed.

## 1. Root Documents

English documentation is placed in the following location.

```txt
docs/
```

Example:

```txt
docs/
├ architecture.md
├ development-flow.md
├ decisions.md
└ rules.md
```

These files are displayed in the **Architecture (English)** section.

## 2. Japanese Documents

Japanese documentation is placed in the following directory.

```txt
docs/ja
```

File naming rules:

```txt
<name>.ja.md
```

Example:

```txt
docs/ja
├ architecture.ja.md
├ development-flow.ja.md
├ decisions.ja.md
└ rules.ja.md
```

These files are displayed in the **Architecture (Japanese)** section.

## 3. Section Documents

If a subdirectory is created, a documentation section is automatically generated.

Example:

```txt
docs/project
docs/maintenance
```

Markdown files within the directory are treated as pages.

Example:

```txt
docs/project
├ policy.md
├ scope.md
└ versioning.md
```

Generated section:

```txt
Project (English)
```

## 4. Japanese Section Documents

For the Japanese version, create the same directory structure in the following location.

```txt
docs/ja/<section>
```

Example:

```txt
docs/ja/project
├ policy.ja.md
├ scope.ja.md
└ versioning.ja.md
```

Generated section:

```txt
Project (Japanese)
```

## 5. Reserved Directories

The following directories are **reserved by the generator and are not treated as normal sections.**

```txt
docs/portal
docs/openapi
docs/coverage
docs/er-diagram
docs/ja
```

## 6. Portal Related Files

The following files are automatically generated and must not be edited manually.

```txt
docs/portal/docs.json
```

To regenerate:

```txt
node scripts/gen-docs-json.mjs
```

## 7. Adding a New Documentation Section

When adding a new section:

```txt
docs/security
docs/ja/security
```

Example:

```txt
docs/security/auth.md
docs/ja/security/auth.ja.md
```

The portal will automatically add the following.

```txt
Security (English)
Security (Japanese)
```

## 8. CI Integration

The documentation portal is automatically updated by CI.

```sh
node scripts/gen-docs-json.mjs
```

## Summary

|配置場所|言語|
|--------|--------|
|docs/*.md|English|
|docs/ja/*.ja.md|Japanese|
|docs/<section>|English セクション|
|docs/ja/<section>|Japanese セクション|

By following these rules, the documentation portal can be maintained with a consistent structure.
