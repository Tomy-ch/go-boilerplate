# pkg/datetime

概要: 日時文字列のパースやフォーマットに関する補助ユーティリティを提供するパッケージです。標準ライブラリの `time` を補助し、入力フォーマットの許容範囲を広げるための関数をまとめています。ロケールやタイムゾーンを考慮したパース機能も含まれます。

## 役割

- 文字列から `time.Time` へ安全に変換するパース関数群を提供する。
- 受け入れる日付/時刻フォーマットの正規化やエラー処理の共通化を行う。
- ロケールおよびタイムゾーンを考慮したパース機能を提供し、多様な入力ソースに対応する。
- テストで使いやすいように、境界ケース（タイムゾーン、省略された項目、DST境界など）の検証ロジックを提供する。

## 必要度

### 本番運用での必須度

- 必須度: 任意

理由: アプリケーションが日時処理を行う場合に有用ですが、標準の `time` パッケージで十分であれば必須ではありません。入力フォーマットが多様な場合は導入を推奨します。

### 開発/テスト運用での必須度

- 必須度: 開発/テスト運用で推奨

理由: 日時パースの差異やフォーマットのばらつきによるバグを防ぐため、共通ユーティリティで取り扱うとテスト容易性と安定性が向上します。

### 無効化した場合の影響

- 日時パース処理を各所で個別実装する必要が生じ、重複や実装差分による不具合が増える可能性があります。
- ロケールやタイムゾーンを考慮した統一的なハンドリングが失われ、テスト網羅性が低下する可能性があります。

## 注意点

- 入力文字列のロケールやタイムゾーンに依存する挙動に注意してください。必要に応じて明示的にタイムゾーンを指定してください。
- 許容するフォーマットを増やすと曖昧なパース結果（意図しない日付変換）が発生する恐れがあるため、ユースケースに応じて取り扱うフォーマットを限定してください。
- パースに失敗した場合のエラーは上位で適切にハンドリングし、ユーザー向けには意味のあるメッセージに変換してください。

## 構成ファイル（ファイル単位の説明）

- `parse.go`: 日時文字列を解析して `time.Time` を返す主要実装。複数のレイアウト対応や省略項目の補完ロジックを含む。
- `parse_test.go`: `parse.go` のユニットテスト。正常系・異常系・境界条件（タイムゾーン、日付フォーマットのバリエーション等）を検証するテストが含まれる。
- `parseloc.go`: ロケールやタイムゾーン情報を考慮した日時パースの補助実装。入力に地域/ロケール特有の表現が含まれる場合の解釈や、明示的なタイムゾーン指定を扱う機能を提供する。
- `parseloc_test.go`: `parseloc.go` のユニットテスト。タイムゾーン変換、ロケール依存のフォーマット、夏時間（DST）境界などのケースを検証するテストが含まれる。
